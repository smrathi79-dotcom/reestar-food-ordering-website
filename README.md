# reestar-food-ordering-website
A simple and responsive food ordering website built using HTML and CSS, featuring delicious food items, order buttons, and a contact form.

# 🍽️ Reestar – Food Ordering Website

## 📌 About the Project

Reestar is a simple food ordering website created using HTML and CSS.
It showcases different food items with images, descriptions, and
Order Now buttons. The website also includes a Contact Us section
for users to enter their details.

## ✨ Features

- 🍜 Displays different food items.
- 🍛 Includes food images and descriptions.
- 🍝 Order Now buttons for each food item.
- 📩 Contact Us section with an input form.
- 🎨 Simple and attractive user interface.
- 💻 Beginner-friendly web development project.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🍴 Food Items

- Noodles
- Biryani
- Pasta
- Fried Chicken

Reestar/
│

## 🚀 How to Run the Project

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the Reestar food ordering website.

## 🎯 Project Objective

The main objective of this project is to practice HTML and CSS
and develop a simple food ordering website with a clean layout.
